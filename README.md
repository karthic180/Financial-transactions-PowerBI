# 💳 Financial Transactions & Merchant Analytics Dashboard

## 🚀 Project Overview
This project is an end-to-end business intelligence solution developed in **Power BI Desktop**, designed to analyze large-scale financial data consisting of **13 million transactions** totaling **$571.84M** in volume[cite: 7]. The goal was to transform complex raw data into a structured, multi-page executive report tracking macro financials, customer demographics, card performance, and global merchant distribution[cite: 7].

---

## 📊 Key Performance Indicators (KPIs)
The executive dashboard highlights the following core metrics[cite: 7]:
* **Total Transaction Amount:** $571.84M[cite: 7]
* **Total Transactions:** 13M[cite: 7]
* **Unique Cardholders / Cards:** 4K Unique Cards / 1K Unique Customers[cite: 7]
* **Credit Performance:** $88.18M Total Credit Limit with an average limit of $14,347[cite: 7]

---

## 🛠️ Technical Implementation & Skills Demonstrated
This repository serves as tangible proof of technical data analysis proficiency, covering:
1. **Data Modeling:** Establishing robust entity relationships between transaction fact tables and dimension tables (customers, cards, merchants).
2. **DAX Measures:** Implementing custom aggregate measures for dynamic calculations and KPIs.
3. **Report UI/UX Design:** Crafting a clean, multi-tab layout consisting of:
   * **Executive Summary:** High-level metrics, gender breakdown, and card type shares[cite: 7].
   * **Card Analysis:** Deep dive into card distribution and credit utilization tiers[cite: 7].
   * **Merchant Analysis:** Geospatial interactive Bing mapping combined with top-performing merchant city rankings (led by Houston, Miami, and Louisville)[cite: 7].

## 🔍 Key Insights Derived
* **Card Breakdown:** Debit transactions represent the majority share of the total transaction volume compared to Credit and Prepaid alternatives[cite: 7].
* **Geographic Trends:** Transaction activity concentrates densely across North American and European hubs, with major physical volume driven out of cities like **Houston and Miami**[cite: 7].
